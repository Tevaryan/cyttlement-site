# Cyttlement Website

A Vite + React + Tailwind landing page for Cyttlement, focused on digital asset settlements and cross-border payments via stablecoins.

## Quick start

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

## Project structure

- `public/logo.png` — Cyttlement logo
- `src/App.jsx` — landing page
- `src/index.css` — Tailwind setup
